# Images

## English Version

This directory stores images referenced by the root README and maintained project documentation.

## Recommended Content

- System architecture and communication-flow diagrams.
- Hardware, connector, and wiring photographs.
- PC controller, MQTT Broker, and UART debugging screenshots.
- Test setup and final assembly photographs.

## File Rules

- Use descriptive English filenames such as `system-architecture.png`.
- Prefer PNG, JPEG, or WebP and avoid unused full-resolution originals.
- Reference images with relative Markdown paths.
- Check all references whenever an image is renamed or replaced.
- Record the source and license for every non-original image.

Before publication, remove account names, passwords, tokens, server details, SIM information, device identities, location data, and unnecessary EXIF metadata.

This directory is for documentation images only. Do not store firmware binaries, installers, or test logs here.

Return to the [project home](../README.md).

# 中文版

本目录保存根目录 README 和项目文档中使用的图片。

## 内容建议

- 系统架构图和通信流程图。
- 硬件实物、接口和接线照片。
- PC 控制端、MQTT Broker 和串口调试截图。
- 测试场景及最终装配效果。

## 文件规范

- 使用能够说明内容的英文文件名，例如 `system-architecture.png`。
- 优先使用 PNG、JPEG 或 WebP；避免提交无用途的原始大图。
- 在文档中使用相对路径，例如 `![System architecture](../images/system-architecture.png)`。
- 图片更新后检查所有引用，避免留下失效链接。
- 对非原创图片记录来源和许可证。

上传前请检查并移除账号、密码、Token、服务器地址、SIM 卡信息、设备标识、定位信息及不必要的 EXIF 元数据。

本目录只存放文档图片，不应保存固件二进制、安装程序或测试日志。

返回[项目主页](../README.md)。
